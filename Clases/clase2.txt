Node no puede ejecutar un archivo en TS, se necesita transpilar
el mismo a JS usando el comando npx tsc, el cual transpila el código TS a JS.

--------------------------------------------------------------------------------
interfaces y types en TS
	* Sirven para definir tipos por el usuario que no sean primitivos de TS
	* Las interfaces se pueden extender, los types no.
	* En el type se deben usar todos los campos declarados dentro del mismo.
Al momento de transpilar a JS, los Types e Interfaces son borrados del archivo.

--------------------------------------------------------------------------------
Barrel pattern
--------------------------------------------------------------------------------
Patrón de exportación, sirve para reducir líneas de importación e importar 
desde un módulo independiente.

Ejemplo:

	En un archivo index.ts dentro de la carpeta ./src/interfaces

	export * from './Empleado';
	export * from './Persona';
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
Nodemon: Dependencia para transpilar los archivos 

Instalación:
	npm install -D nodemon
	npm install -D ts-node

Nodemon tiene un archivo de configuración, el mismo se debe crear bajo el nombre nodemon.json (carpeta raiz del proyecto)

{
	"watch": ["src"],
	"ext": ".ts, .js",
	"ignore": [],
	"exec": "npx ts-node ./rutaAplicacion" 
}

Para ejecutar:
	npx nodemon

Dentro del package.json se puede agregar el script "dev": "nodemon"


Script build: Dentro del package.json agregar:
	"scripts": {
		 "build": "tsc"
	}
Se puede ejecutar el comando agregado usando: npm run build

--------------------------------------------------------------------------------
Rimraf: Dependencia para eliminar carpetas en cada build
	npm install -D rimraf
agregar al script build (en package.json)
	"scripts": {
		...
		"build": "rimraf ./dist && tsc"
	}
Se pueden combinar los comandos para que se ejecute todo el proceso de 
borrar carpetas, transpilado y ejecución del programa en un comando.
	"start": "npm run build && node dist/app.js"

import { createServer } from 'http';


const server = createServer((request, response) => {
	const url = request.url;
	console.log(`Recibimos tu request en la url ${url}`);
	if(url === '/personas'){
		response.writeHead(200);
		response.end(JSON.stringify(personas))	
	} else {
		response.end(`Tu respuesta a la ${url} es Hola mundo`);
	}
})

server.listen(3000, () => {
	console.log('Servidor funcionando en puerto 3000');
})
